# Studyhausen

A private, calm study companion for exam preparation.

## First prototype

This starter version is a simple browser app focused on Science. It includes:

- a gentle home screen;
- Science topic cards;
- Cells flashcards;
- a short Cells quiz;
- progress tracking saved in the browser;
- placeholder topics ready for her own school material.

## Run it

No installation is needed. Open `index.html` in a browser.

In Codespaces, you can use the **Live Server** extension or run a small local server from the terminal:

```bash
python3 -m http.server 8000
```

Then open port `8000` when Codespaces offers it.

## Important note

The current Science content is demonstration material only. Before using it for exam preparation, we will replace or expand it using her actual class notes and textbook topics.
